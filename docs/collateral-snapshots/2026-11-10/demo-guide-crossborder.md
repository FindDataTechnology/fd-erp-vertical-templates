## 动线（脚本章节即演示动线）

### 第 1 章 · 账本内核五连（约 5 分钟，讲「为什么账可信」）

| 步骤 | 你说什么 | 屏幕上指什么 |
|---|---|---|
| 1.2 agent 提交 proposal | 「agent 只能提提案，账本状态零变化」 | `status: pending`，1300 余额仍 0 |
| 1.3 owner 确认 | 「唯一落账路径是确认门」 | 1300 借 100.00 / 4000 贷 100.00 |
| 1.4 幂等 | 「平台重推是常态，同 stable_id 返回原结果」 | `same_proposal_id: true` |
| 1.5 不平分录 | 「借 50 贷 40——看数据库怎么回答」 | `ERP_UNBALANCED`（PL/pgSQL 约束层拒绝），余额纹丝不动 |
| 1.6 冲正 | 「错账不删不改，红字冲销，原分录永远可查」 | 4 条分录、2 条冲正关联 |

**话术要点**：这三个保证不是应用层自觉，是数据库约束（DEFERRABLE 触发器 +
append-only 触发器 + 唯一索引）——「我们相信约束，不相信 agent 的自觉」。

### 第 2 章 · 三方对账（约 8 分钟，讲「你要的东西」）

| 步骤 | 你说什么 | 屏幕上指什么 |
|---|---|---|
| 2.1 订单↔收款 | 「4 笔差异，每条带双侧原始单号」 | 金额不符 250/240、缺笔 80、缺笔 60、多出 500 |
| 2.2 订单↔库存 | 「没扣库存的那单自动标在途，引用物流证据，不猜」 | `needs_explanation=logistics` |
| 2.3 费用报表 | 「payouts 840、佣金 15、支付手续费 2，费率带出处」 | `shopify-rate-card` explained |
| 2.4 escalate | 「定性不了的，升级到您拍板，材料自动生成」 | `severity: high` |
| 2.5-2.6 拍板回写 | 「您拍板后，agent 只挂应收，USD 10 差额按 7.20（ecb-exr 出处）折算 CNY 72 入账」 | 1300 USD 行 balance 72 |

**话术要点**：差异清单每条含双侧原始引用——「这就是和 Excel 对账的本质区别：
不止告诉你差多少，还告诉你差在哪、为什么、单号是多少」。

### 第 3 章 · 两条红线（约 4 分钟，讲「你们敢把账交给我们」）

| 步骤 | 你说什么 | 屏幕上指什么 |
|---|---|---|
| 3.1 资金红线 | 「结论里出现『自动打款』，模板层直接拒绝」 | `SHARE_EXECUTION_DENIED` |
| 3.2 租户隔离 | 「拿 A 租户身份问 B 租户进程——拒绝」 | `TENANT_DENIED` + 审计留痕 |

**话术要点**：「平台不经手资金：对账只产出核对数据，划转走您自选的持牌通道。
这两条是写进规格的硬约束，不是口头承诺。」

## 关键数字备忘（2026-11-07 实跑）

- 订单 4 笔 / 收款 3 笔 / 库存 3 条 → 配对成功 1 · 差异 4 条 · 重推去重 0
- 差异：金额不符 10 USD（250↔240）、缺笔 80、缺笔 60、多出 500
- 费用：payouts 840 / 佣金 15 / 支付手续费 2（费率 0.15，出处 shopify-rate-card）
- 拍板落账：USD 10 → CNY 72（汇率 7.20，出处 ecb-exr，as_of 2026-11-07）
- 错误码实拍：`UNBALANCED` / `FX_UNSOURCED` / `SHARE_EXECUTION_DENIED` / `TENANT_DENIED`

## Q&A 守界口径（如实回答）

- **能不能接我们的真店？** 能，商家自带 Shopify API 凭证（BYOK）逐店开通，
  token 不落库不出日志；**当前是「需一次接入」而非已接通**——今天演示用的是合成店，
  签约后第一件事就是接您真店做只读 POC。<!-- capability:shopify.orders=unmapped -->
- **收款/结算对账能做吗？** 结算面（payouts）待补 provider 动作，当前标**不可得**，
  不拿订单金额推算结算额。<!-- capability:shopify.settlements=unmapped -->
- **库存腿呢？** 同上，未接通前不出「库存零差异」的结论。<!-- capability:shopify.inventory=unmapped -->
- **国内平台（淘宝/天猫/京东）？** 是「需一次接入」，不是「不支持」：目录里还没有这三家的
  provider，接进来需要一次接入；商家电商 ERP 通道是补库存腿的首选。<!-- capability:taobao.orders=unmapped -->
- **拼多多？** 当前不提供（上游接口 schema 缺失），如实告知，不承诺接入日期。<!-- capability:pinduoduo.orders=unavailable -->
- **能帮我们记账/报税吗？** 开票/税务当前不提供；账内可记录发票事件参与对账，
  票据走您既有合规渠道。
- **能不能直接替我们补货/发货？** 执行走您授权的外部系统（如 Shopify），我们
  只做记录与对账，动作前经确认门。
- **汇率哪来的？** ecb-exr 观测流，每笔带 as_of；无出处汇率内核直接拒绝（可现场演示）。
