# BossAI 聚合应用平台 — 逐项对照与打法

> 属地：宜昌市 ｜ 合作方式：战略合作、培训孵化、内容创作
> ⚠️ **前置风险**：检索"BossAI 聚合应用平台""BossAI 宜昌"均无任何政务采购痕迹。项目真伪需先向需求方核实。以下按"项目为真"展开。

## 一、需求原文拆解

平台自述："模型聚合、AI工具、内容创作、算力供应"四位一体；聚合主流大模型与多模态能力；统一API、统一Token计费屏蔽底层异构；沉淀 200+ 开箱即用 AI 工具；开放 Agent 开发框架；面向政府/央国企提供私有化部署、专网接入、合规审计；围绕"1个入口+4大主线+N个场景"；统一账户体系打通跨模型调度与跨工具协同。

四条产线：
- **办公效率线**：文档、表格、演示、会议纪要
- **视觉设计线**：海报、UI、品牌素材
- **影视制作线**：脚本、分镜、剪辑、特效

N 个场景：无限画布、知识库问答、AI写作、智能客服、跨境电商、AI面试官、影视分镜师。

六项底座：算力调度、Token计量、Agent编排、权限审计、数据合规、安全沙箱。

## 二、逐项对照（诚实标注）

### 2.3 六项底座

| 底座 | 现状 | 证据 |
|---|---|---|
| Token计量 | **生产** | sub2api + audit_events + preflight 闸 |
| Agent编排 | **生产** | 萬星 A2A + agent-runner；spider-heal 自愈 Agent 在役（修复流+生成流 v6，4 技能，自动开 PR） |
| 权限审计 | **生产（二稿加强）** | MCP 网关 Logto IAM + scope→group 授权；四层权限闸（组/scope/计费/凭据）；调用级审计。**二稿新增实物**：团队空间二期——owner/editor/viewer 三角角色门禁（入统一鉴权依赖）、席位配额按档位硬停、成员/邀请/角色变更 **append-only 留痕**；资产目录的元数据修改**逐次留痕可查**（谁、何时、改了什么）。政务评审问"谁能改、留没留痕"时有实物可演示 |
| 数据合规 | **部分** | 有原始审计事件，**无合规级审计报告**（无导出/报告/签名产品）；但**溯源账本可作底**（哈希链+离线验签证据包，识律线已有） |

## 三、打法建议

**报"底座 + 分阶段场景"，不报"全能"。**

```
第一阶段（可现场演示，全部在产）
  1个入口（三端） / 统一API / 每租户key+余额 / 调用级审计
  MCP网关 548工具 + 152技能 / Agent编排+交付
  知识库RAG（可私有化） / Pack市场
  私有化交付包构建器（识律线已有）

第二阶段（配置 + 复用，工作量小）
  办公效率线（文档/表格/演示）+部分N场景（AI写作/知识库问答）

第三阶段（新建，需明确工期与预算）
  视觉设计线（海报/UI/品牌素材）
  影视制作线（脚本/分镜/剪辑/特效）
  算力调度 / 合规审计报告 / 安全沙箱产品化
  剩余N场景（无限画布/AI面试官/智能客服产品）
```

**关键话术**：把"1个入口 + 底座能力"报成**已具备、可现场演示**；把办公效率线与部分场景报成**现成 + 配置**；把**视觉、影视两条线明确标为分阶段建设**。需求原文写着"战略合作、培训孵化"——对方要的是长期关系，**诚实标注缺口比全包承诺更容易拿到阶段一**。

## 四、风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| **项目真伪** | 检索无采购痕迹 | 先核实再投入 |
| **省级平台已覆盖** | 湖北大数据集团"湖北省智能体公共服务平台"（1+4+3 AI工厂：算力-数据-模型-场景）2026-04 上线；算力互联互通平台已接入武汉/宜昌/襄阳集群（可监测 7000P+、可调度 2000P+） | 定位为**市级/项目级落地与场景供给**，与省级平台互补而非竞争 |
| **重资产对手** | 点军区 AI 政务智能体 2.48 亿（区属国企聚辉数智）+ 算力枢纽 EPC 7.4 亿（中贝通信，昇腾910B） | 不打算力基础设施；打**应用与场景供给** |
| **联想已入场** | 2025-03 与宜昌签"城市超级智能体"合作协议（1×N 智能体方案） | 差异化在**可私有化 + 数据侧供给**（联想是硬件+方案，我们是数据+应用） |
| **算力供应是硬缺口** | "算力供应"是四条主线之一，我们零基础 | 明确报为合作项（对接本地算力枢纽），或列为非本期范围 |

## 五、一句话结论

**BossAI 是本批五个项目里与我们底座最同构的一个**——"1个入口+统一API+统一计费+工具市场+Agent编排+私有化"这六项我们有在产的实物。**缺的是算力、视觉产线、影视产线，以及一半的 N 场景。** 打法应是"底座全包 + 场景分阶段"，并**先确认项目真伪**。
